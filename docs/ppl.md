## Reproducing

```sh
# base logits from the unquantized model (16 GB for 128 chunks)
llama-perplexity -m model-BF16.gguf -f wiki.test.raw -ngl 99 -c 512 \
    --chunks 128 --kl-divergence-base base-128.kld

# per scheme: quantize both ways, then score each against the base logits
llama-quantize --imatrix imatrix.gguf model-BF16.gguf lq.gguf IQ3_S
python quant-studio.py model-BF16.gguf qs.gguf IQ3_S --imatrix imatrix.gguf --mem 4G
llama-perplexity -m lq.gguf -ngl 99 -c 512 --kl-divergence --kl-divergence-base base-128.kld
llama-perplexity -m qs.gguf -ngl 99 -c 512 --kl-divergence --kl-divergence-base base-128.kld
```
